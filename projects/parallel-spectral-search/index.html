THE COMPUTE PATTERN

Partition. Match. Reduce.

01 / DISTRIBUTE

Break up the data

Independent spectrum archives become HTCondor jobs, distributing the search across a high-throughput compute environment.

02 / MATCH

Search each spectrum

R and FITSio slide the cB58 reference flux vector across each input spectrum, retaining the minimum Euclidean distance and its location.

03 / RANK

Merge the strongest matches

Distributed CSV outputs are combined and globally sorted to produce the 100 closest candidates from the full search.

01 / WHY TOPOLOGY

What is missing
is part of the shape.

Geometric closeness alone does not tell the whole story. Controlled holes make structural errors visible, creating a testbed for completion models that need to preserve more than the surface.

02 / THE APPROACH

Geometry meets
a topology descriptor.

Topo-PCN adds a small learned topology branch to a PCN-style network. The decoder receives geometric features together with a descriptor of the input’s persistent structure.

From the presentation to the current implementation

The presentation explores per-point topology channels and a combined Chamfer + H1 bottleneck objective. The current released code instead fuses a learned three-value descriptor with the geometric latent code and trains with differentiable coarse/fine Chamfer losses. GUDHI H1 bottleneck distance runs outside PyTorch autograd and is an evaluation/monitoring metric. These implementation details should be distinguished from the original proposed objective.

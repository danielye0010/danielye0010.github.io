02 / HOW IT WORKS

Adapt the weights.
Reveal the intent.

WDIB stands for Weighted and Density-Aware Intent Bubble. In dense regions, proximity receives more weight; in sparse regions, the direction of motion contributes more.

01 / DISTANCE

How close is it?

A smooth, clamped distance score favors nearby targets inside the configured detection range.

Dᵢ = clamp(1 − dᵢ / R, 0, 1)
02 / TRAJECTORY

Where are you heading?

The alignment between hand movement and the direction to each candidate estimates the next intended target.

Tᵢ = max(0, v̂ · p̂ᵢ)
03 / DENSITY

How crowded is it?

The nearby candidate count shifts the balance between distance and directional alignment.

ρ = clamp(Nnear / 12, 0, 1)
THE RELEASED CODE

Sᵢ = (0.7 + 0.4ρ) Dᵢ + 0.3(1 − ρ) Tᵢ

Exposed script defaults. Unity Inspector settings can override them.

04 / THE STUDY

Five people.
Three techniques.

A within-subjects VR study asked five adult volunteers to select five targets in a high-density scene with 300 distractors. Each participant used all three techniques.
